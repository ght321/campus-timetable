# 3–5分钟课程设计演示

演示前执行npm ci、npm run dev，保持同一浏览器地址。先导出需要保留的数据，再恢复演示课表。若今天不在示例学期，设置真实学期或选择第7周，说明“显示周”和“真实当前周”的区别，不伪造时间。

1. **0:00–0:40，A**：展示品牌、真实日期、周切换和回到本周；跳到第20周展示空状态，说明数据驱动统计。
2. **0:40–1:40，A**：新增“软件工程实践”，故意选择与数学重叠的时间，展示具体冲突周，勾选后保存。查看详情、编辑到星期日、名称搜索、删除确认。
3. **1:40–2:30，B**：演示单双周在相邻周切换。开学日期设2026-12-28，跳第2周显示2027-01-04。尝试周数缩到8，展示现有课程越界拒绝。
4. **2:30–3:20，B**：导出JSON、刷新验证恢复。导入先取消，再预览确认。解释schemaVersion、学期字段、旧版转换。
5. **3:20–4:20，A/B**：A展示手机宽度和课表局部横向滚动；B展示58项单测、7项Chromium测试及模块职责。明确单浏览器存储与人工验收边界。

压缩到3分钟可用准备的JSON演示跨年，省去逐字段输入。不能只用截图代替实际操作。结束时恢复需要的学期配置并导出备份。
